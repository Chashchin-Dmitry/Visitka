# Цифровая визитка - Дмитрий Чащин

Современная веб-визитка с QR-кодом для конференций и деловых встреч.

## Что внутри

- Адаптивная HTML-визитка с брендингом BVMax
- Все контакты в одном месте (телефон, email, Telegram, LinkedIn, WhatsApp)
- Оптимизирована для мобильных устройств
- Быстрая загрузка, без зависимостей

## Быстрый старт

### Шаг 1: Добавьте фото профиля

Сохраните ваше фото (то, что вы прислали) как `profile.jpg` в папку `assets/images/`:

```bash
# Вариант 1: Скопируйте файл вручную
# Переименуйте ваше фото в profile.jpg и положите в digital-card/assets/images/

# Вариант 2: Используйте командную строку (если фото уже сохранено)
cp /путь/к/вашему/фото.jpg digital-card/assets/images/profile.jpg
```

**Требования к фото:**
- Формат: JPG, PNG
- Рекомендуемый размер: 500x500px или больше (квадратное)
- Максимальный размер файла: 500KB

### Шаг 2: Проверьте локально

Откройте `index.html` в браузере:

```bash
# macOS
open digital-card/index.html

# Или просто двойной клик на файл index.html
```

### Шаг 3: Загрузите на GitHub Pages

#### 3.1 Создайте GitHub репозиторий

1. Перейдите на https://github.com/new
2. Название: `digital-card` (или любое другое)
3. Выберите **Public**
4. НЕ создавайте README (у нас уже есть)
5. Нажмите **Create repository**

#### 3.2 Загрузите файлы

```bash
cd digital-card

# Инициализируйте git репозиторий
git init

# Добавьте все файлы
git add .

# Создайте первый коммит
git commit -m "Initial commit: digital business card"

# Добавьте удаленный репозиторий (замените USERNAME на ваш GitHub username)
git remote add origin https://github.com/USERNAME/digital-card.git

# Загрузите на GitHub
git branch -M main
git push -u origin main
```

#### 3.3 Включите GitHub Pages

1. Откройте настройки репозитория: `Settings` → `Pages`
2. В разделе **Source** выберите: `Deploy from a branch`
3. В **Branch** выберите: `main` и папку `/ (root)`
4. Нажмите **Save**
5. Подождите 1-2 минуты

Ваша визитка будет доступна по адресу:
```
https://USERNAME.github.io/digital-card/
```

### Шаг 4: Создайте QR-код

#### Вариант 1: QR Code Generator (рекомендуется)

1. Перейдите на https://www.qr-code-generator.com/
2. Выберите тип: **URL**
3. Вставьте ссылку на вашу визитку: `https://USERNAME.github.io/digital-card/`
4. Настройте дизайн (опционально):
   - Цвет: `#ff8502` (оранжевый BVMax) или `#114efe` (синий)
   - Можно добавить логотип BVMax в центр
5. Скачайте в высоком разрешении (SVG или PNG 2000x2000px)

#### Вариант 2: QR Tiger (бесплатно)

1. Перейдите на https://www.qrcode-tiger.com/
2. Вставьте URL визитки
3. Настройте цвета под бренд BVMax
4. Скачайте QR-код

#### Вариант 3: Goqr.me (простой)

1. Перейдите на https://goqr.me/
2. Вставьте URL
3. Выберите размер: **L (большой)**
4. Скачайте PNG

### Шаг 5: Использование QR-кода

**Для печати:**
- Распечатайте QR-код на бейдж/визитку
- Рекомендуемый размер: минимум 3x3 см
- Формат: SVG или PNG высокого разрешения

**Для экрана:**
- Сохраните QR-код на телефон
- Показывайте с экрана на конференциях
- Люди сканируют → переходят на вашу визитку → сохраняют контакты

## Обновление визитки

### Изменить контакты или информацию

1. Откройте `index.html` в текстовом редакторе
2. Найдите нужный блок (например, email или телефон)
3. Измените информацию
4. Сохраните и загрузите на GitHub:

```bash
git add index.html
git commit -m "Update contact info"
git push
```

GitHub Pages автоматически обновит сайт через 1-2 минуты.

## FAQ

**Q: Что если у меня нет GitHub аккаунта?**
A: Создайте бесплатно на https://github.com/join

**Q: Можно ли использовать свой домен?**
A: Да! В настройках GitHub Pages → Custom domain

**Q: Визитка платная?**
A: Нет, полностью бесплатно (GitHub Pages + бесплатные QR-генераторы)

**Q: Можно ли отслеживать переходы по QR-коду?**
A: Да, используйте короткие ссылки с аналитикой:
- Bitly (https://bitly.com) - бесплатно
- Rebrandly (https://www.rebrandly.com) - бесплатно
